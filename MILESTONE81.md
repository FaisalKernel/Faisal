# FAISAL M81 — Concurrent Lifecycle and IPC Stress Validation

## Status

M81 is **validated in the bounded QEMU test environment** and is ready for commit and tag after the governance follow-up is completed. The implementation adds a userspace concurrency stress service and executable selftest; it does not change the stable FAISAL ABI or add model authority to the kernel.

The test creates **eight independent `/dev/agi_lifecycle` sessions** concurrently. Each session registers a planner source light-agent and a verifier child light-agent, creates a capability-scoped IPC channel, exercises malformed-input rejection and capability denial, queues cancellable messages, then runs a concurrent producer/consumer round trip. Message fields are generated by a deterministic per-worker xorshift32 stream so that structured inputs vary reproducibly without introducing nondeterministic test oracle behavior.

## Acceptance Results

The clean recovered FAISAL kernel passed all M81 assertions: eight workers and eight worker passes; 512 malformed UAPI inputs rejected; 16 capability-isolation denials; 48 message cancellations; 768 messages sent and received; 872 randomized valid structured inputs; nonzero queue-pressure observations; and clean selftest exit. The final tracked full regression passed **21/21 QEMU harnesses**.

A suite-only failure in the verified-research harness was reproduced twice. Independent reruns passed. The tracked audit runner was strengthened to rebuild the current verified-research selftest from source, after which the complete 21-harness audit passed. This is recorded as a reproducibility fix, not hidden as a transient failure.

The same M81 selftest passed on separately built **Generic KASAN + lockdep** and **strict KCSAN + lockdep** kernels. No KASAN, KCSAN, lockdep, panic, or Oops signatures were present in the final sanitizer QEMU logs. The KASAN two-vCPU exploratory run emitted RCU starvation warnings under heavy instrumentation; the final four-vCPU KASAN run completed without those warnings and is the recorded sanitizer result. The warning is retained as an infrastructure observation rather than suppressed.

## Security Boundary

The stress service performs only lifecycle-device operations and local test coordination. It contains no process-launch primitive, identity-changing call, `ptrace`, `CAP_SYS_ADMIN`, model invocation, network client, or privileged authorization path. Model output is not used. The test explicitly verifies that a mutated sender capability and a mutated channel capability are denied by the kernel.

> M81 validates concurrent enforcement and failure behavior; it does not grant authority, bypass capability checks, or convert a test result into authorization.

## Limitations

M81 is not a proof of race freedom. KCSAN is a sampling detector and can miss races; the official documentation describes this limitation explicitly. The test also does not claim hardware accelerator concurrency, long-duration soak coverage, syzkaller coverage, formal verification, production readiness, or complete scheduler scalability. The IPC channel model remains the existing ABI 37 model, including session-scoped channel ownership.
